# CLI reference

The command-line interface below is generated on every docs build directly from
the live `mibare.cli.app` Typer application (via `typer ... utils
docs`), so the documented commands, options, and defaults are always exactly what
the code exposes — they cannot drift from `--help`. `mibare` is a single
command with no subcommands.
